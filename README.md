## 📖 Overview

This repository documents my practical learning journey across **web application security, reconnaissance, exploitation, vulnerability analysis, steganography, and offensive security techniques**.

Each writeup walks through the methodology end to end: enumeration, identifying the weakness, exploitation, and key takeaways.

> [!WARNING]
> **Disclaimer:** All testing documented here was performed against intentionally vulnerable systems in authorized training and CTF environments. The techniques and commands are provided for **educational purposes only**.

## 🧪 Lab Categories

### 🌐 Web Application Security

Writeups covering common web vulnerabilities and offensive techniques:

- Broken Access Control
- Broken Authentication
- Command Injection
- Insecure Deserialization
- Server-Side Template Injection (SSTI)
- XML External Entity (XXE)
- Source Code Analysis
- Authentication & Authorization Testing
- Web Enumeration & Reconnaissance
- Exploitation of intentionally vulnerable applications

### 🔐 Steganography

Challenges involving hidden information, file analysis, metadata inspection, and steganographic techniques.

### 🧩 Miscellaneous

Challenges involving encoding, obfuscation, file analysis, and other techniques that don't fit the primary categories.
